# 🚨 Multi-Model Hate Speech Recognition

A machine learning project designed to classify hate speech from text data using multiple models and techniques. This system analyzes input text and determines whether it contains harmful, offensive, or hate speech. The project uses natural language processing (NLP) methods and combines multiple machine learning models to increase classification accuracy.

---

## 🚀 Tech Stack Used

- **Languages**: Python
- **Libraries/Frameworks**:
  - **Scikit-learn** (for ML algorithms)
  - **TensorFlow/Keras** (for deep learning models)
  - **NLTK** (Natural Language Toolkit for text processing)
  - **pandas** (data manipulation)
  - **NumPy** (scientific computing)
  - **matplotlib / seaborn** (visualization)
- **Tools**:
  - **Jupyter Notebook** (for experimentation)
  - **Git** (version control)

---

## ✅ Features

- 🧠 Multi-model approach using various machine learning algorithms (e.g., SVM, Random Forest, LSTM)
- 📝 Text preprocessing and vectorization techniques (e.g., TF-IDF, Word2Vec)
- 🎯 Model performance evaluation metrics (e.g., accuracy, precision, recall, F1-score)
- ⚡ Real-time hate speech classification
- 💾 Dataset support for text preprocessing and model training
